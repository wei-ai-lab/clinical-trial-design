# gsdesign-mcp — discoverability alias

This package is a redirect stub. The canonical name is **`clinical-trial-design`**.

```bash
npm install clinical-trial-design
# or, to run the MCP server directly:
npx clinical-trial-design
```

Project home: https://github.com/wei-ai-lab/clinical-trial-design

Wraps the `gsDesign` (Keaven Anderson) and `gsDesign2` (Yujie Zhao et al.) R packages as 13 MCP tools — sample size, group-sequential boundaries, NPH (MaxCombo / RMST / milestone), Monte Carlo verification, markdown reporting.
