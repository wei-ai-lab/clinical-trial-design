# HPS (2002) — Simvastatin × Antioxidants in High-Risk CV

**Family:** factorial · **Kind:** primary-results · **N:** 20,536 · **Endpoint:** major vascular events + all-cause mortality · **Design:** 2×2 at-the-margins

## Why this case is in the corpus

- **Canonical large factorial** with one positive and one null factor — teaches the factorial failure mode and its mitigation by pre-specified interaction testing.
- Oxford CTSU-style large-simple-trial design, sibling to ISIS-2 and GISSI.
- Pivotal trial extending statins to diabetics and high-risk non-hyperlipidemic populations.
- Decisively ended the antioxidant-for-CV-prevention hypothesis.

## Citation

Heart Protection Study Collaborative Group. *MRC/BHF Heart Protection Study of cholesterol lowering with simvastatin in 20,536 high-risk individuals: a randomised placebo-controlled trial.* Lancet. 2002 Jul 6;360(9326):7-22. (Antioxidant factor paper on pp 23-33.)

## Design summary

| Element | Value |
|---|---|
| Population | UK adults 40-80, high CV risk (CHD / stroke / PAD / DM) |
| Randomization | 2×2 factorial, 1:1:1:1 |
| Factor 1 | Simvastatin 40mg/day vs placebo |
| Factor 2 | Antioxidant (vit E 600 + C 250 + β-carotene 20 mg) vs placebo |
| Primary (co) | Major vascular events; all-cause mortality |
| Analysis | At-the-margins per factor; interaction test pre-specified |
| Follow-up | Mean 5.0 years |
| α | 0.05 two-sided; power 0.90 |

## Reproducing the design

```r
# HPS factorial: each marginal comparison
# MVE rate over 5 years: placebo ≈ 25%, simvastatin ≈ 20%, ARR 5%
library(gsDesign)
nBinomial(
  p1 = 0.25, p2 = 0.20,
  alpha = 0.05, beta = 0.10, sided = 2
)
# ≈ 1,300 per arm for 2-arm trial
# Factorial halves enrollment: 10,000 per factor margin from 20,000 total

library(stats)
power.prop.test(
  p1 = 0.25, p2 = 0.20,
  sig.level = 0.05, power = 0.90
)
```

## Trial outcome

| Outcome | Simvastatin | Placebo | p |
|---|---|---|---|
| Major vascular event | 2,033 (19.8%) | 2,585 (25.2%) | < 0.0001 |
| All-cause mortality | 1,328 (12.9%) | 1,507 (14.7%) | 0.0003 |
| Antioxidant: MVE | 2,306 (22.5%) | 2,312 (22.5%) | NS |
| Antioxidant: mortality | 1,446 (14.1%) | 1,389 (13.5%) | NS |

Interaction (simvastatin × antioxidant): pre-specified test, not significant on any endpoint — confirms at-the-margins analysis validity.

## Factorial design decision points

- **Why factorial worked**: independent mechanisms (lipid-lowering vs antioxidation), no interaction, large enough sample per margin.
- **Why null factor didn't break the trial**: pre-specified interaction test, confirming additivity; the null antioxidant factor did not bias the simvastatin margin.
- **McAlister criteria met** (2003 case in corpus): factorial justified when both factors have plausible independent mechanisms and no qualitative interaction is anticipated.

## Historical impact

- Extended statin eligibility to diabetics and high-risk normolipidemic patients.
- Ended clinical interest in antioxidant vitamins for CV prevention (joining HOPE 2000 on vitamin E).
- Set the template for later factorial trials: HPS2-THRIVE (2014), SEARCH (2010).
- Methodological influence on HOPE-3 (in corpus) and other subsequent factorial designs.

## How this case validates designr

- Complements ISIS-2 and HOPE-3 as the second-largest-factorial case in the corpus.
- Illustrates the key factorial design decision: pre-specified interaction test and at-the-margins vs inside-the-table reporting.
- `designr` should be able to size a 2×2 factorial where each factor's marginal arms are powered per conventional 2-arm binary-proportion calculation, and expose the interaction test as a secondary analysis element.
