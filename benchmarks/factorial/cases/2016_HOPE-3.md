# HOPE-3 (2016) — 2×2 factorial rosuvastatin + candesartan/HCTZ primary CV prevention

**Family:** factorial · **Endpoint:** MACE composite · **N:** 12,705 · **Design feature:** canonical 2×2 factorial CVOT

## Why this case is in the corpus

- **Canonical modern 2×2 factorial CVOT** — lipid + BP factors tested simultaneously.
- Primary prevention in intermediate-risk (lower event-rate setting).
- Established statin benefit in broader primary prevention population.

## Citation

Yusuf S, Bosch J, Dagenais G, et al. *Cholesterol lowering in intermediate-risk persons without cardiovascular disease.* N Engl J Med. 2016;374(21):2021-2031. doi:10.1056/NEJMoa1600176. NCT00468923.

(Companion: Lonn EM et al. BP factor. NEJM 2016;374:2009-2020.)

## Design summary

| | |
|---|---|
| Design | 2×2 factorial RDBPC |
| Population | Intermediate-risk primary prevention (no CVD) |
| Factor 1 | Rosuvastatin 10 mg vs placebo |
| Factor 2 | Candesartan 16 + HCTZ 12.5 vs double placebo |
| Primary | MACE composite TTE |
| α per factor | 0.05 (two-sided) |
| Power | 0.80 per factor |
| Assumed HR per factor | 0.80 |
| Control annual event rate | ~1.5% |
| Target events | 615 |
| Planned N | 12,705 |

## Trial outcome

- **Statin factor**: MACE HR **0.76** (95% CI 0.64-0.91), p = 0.002 → co-primary MET.
- **BP factor**: MACE HR **0.93** (0.79-1.10), p = 0.40 → negative.
- **Combined (both active)**: HR **0.71** (0.56-0.90), p = 0.005.
- No statin × BP interaction detected.
- LDL reduction ~ 35 mg/dL on rosuvastatin.
- Reshaped primary prevention guidelines for intermediate-risk.

## How this case validates designr

- Canonical 2×2 factorial CVOT reference.
- Two independent primary factors at α = 0.05 each.
- Large-N, low-event-rate primary prevention sizing.
- No-interaction assumption validated.
