# ISIS-2 (1988) — Streptokinase × Aspirin in Acute MI

**Family:** factorial · **Kind:** primary-results · **N:** 17,187 · **Endpoint:** 5-wk vascular mortality · **Design:** 2×2 at-the-margins

## Why this case is in the corpus

- **Most influential 2×2 factorial trial ever conducted** — definitively established both aspirin and streptokinase in acute MI on a single trial.
- Canonical illustration of the **at-the-margins** analysis strategy (McAlister 2003 taxonomy).
- Orthogonal randomization gave each factor ~17,000 patients in its marginal comparison — far larger than any stand-alone 2-arm trial would have achieved.
- Historical exemplar of the large-simple-trial paradigm (Oxford CTSU / Sleight-Collins-Peto).

## Citation

ISIS-2 (Second International Study of Infarct Survival) Collaborative Group. *Randomised trial of intravenous streptokinase, oral aspirin, both, or neither among 17,187 cases of suspected acute myocardial infarction: ISIS-2.* Lancet. 1988 Aug 13;2(8607):349-60.

## Design summary

| Element | Value |
|---|---|
| Population | Suspected AMI within 24h of symptom onset |
| Randomization | 2×2 factorial, 1:1:1:1 |
| Factor 1 | Streptokinase 1.5MU IV vs placebo |
| Factor 2 | Aspirin 162.5mg/day × 1 month vs placebo |
| Primary endpoint | 5-week vascular mortality |
| Analysis | At-the-margins (marginal comparisons per factor) |
| Interaction | Pre-specified tested but not powered for |
| α | 0.05 two-sided |
| Power | 0.80 (per marginal comparison) |

## Reproducing the design

```r
# ISIS-2 factorial: each marginal comparison
# control mortality ≈ 12%, RRR per factor ≈ 20%
# → control = 0.12, treatment = 0.096

library(stats)
power.prop.test(
  p1 = 0.12, p2 = 0.096,
  sig.level = 0.05, power = 0.80,
  alternative = "two.sided"
)
# n per arm ≈ 2,700; for marginal comparison, each factor's arms have
# ~8,500 patients (half of total 17,187), far exceeding the
# conventional power requirement → the factorial design gave
# essentially double-duty enrollment.

# gsDesign equivalent
library(gsDesign)
nBinomial(p1 = 0.12, p2 = 0.096, alpha = 0.05, beta = 0.20, sided = 2)
```

## Trial outcome (primary endpoint, 5-week vascular death)

| Arm | Events / N | Rate |
|---|---|---|
| Placebo / Placebo | 568 / 4,300 | 13.2% |
| Streptokinase / Placebo | 448 / 4,295 | 10.4% |
| Placebo / Aspirin | 461 / 4,295 | 10.7% |
| Streptokinase / Aspirin | 343 / 4,292 | 8.0% |

**Marginal comparisons**:
- Streptokinase: 9.2% vs 12.0% (p < 0.00001).
- Aspirin: 9.4% vs 11.8% (p < 0.00001).
- Nearly additive combination benefit.

## Historical impact

- Established aspirin in acute MI — now universal standard of care.
- Validated streptokinase as a practical, low-cost thrombolytic.
- Methodological template for subsequent ISIS-3 (3×2), ISIS-4 (3×2×2), GISSI-3 (2×2), and HPS (2×2) trials.
- Widely cited as the archetype of 'cheap, simple, big' trials that yield definitive answers.

## How this case validates designr

- Canonical at-the-margins 2×2 factorial — complements the McAlister (2003) methodology case and HOPE-3 (2016).
- Sample-size derivation is directly reproducible via per-factor marginal binary-proportion power calculation.
- Teaching case for when factorial makes sense: independent mechanisms, no qualitative interaction expected, large patient populations feasible.
